# 3D Mars Simulator

一个可以在浏览器中运行的 3D 火星模拟器。通过左侧控制台可在火星表面任意位置创建地名并定位标记。点击任意标记或列表中的地名会弹出详情卡片，支持上传图片或视频并记录多行文本。

## 功能特性

- 使用 Three.js 构建的 3D 火星球体，支持旋转、缩放和漫游
- 控制台输入地名、纬度和经度后即可创建地标，自动出现在球体上
- 所有地标都会在 3D 视图中显示高亮标签，并同步展示在列表中
- 点击地标或列表项弹出详情卡片，支持：
  - 上传图片或视频（浏览器本地预览）
  - 多行文本输入，记录任务说明或观察内容
- 响应式布局，兼容桌面和移动端

## 本地运行

```bash
npm install
npm run dev
```

> 说明：本项目依赖 Vite 与 React 构建。如果在离线或受限网络环境下无法安装依赖，请在具备 npm 访问权限的环境中执行上述命令。

运行开发服务器后，使用浏览器访问命令行输出的地址（通常为 `http://localhost:5173`）即可体验 3D 火星模拟器。
