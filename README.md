# Mingming Snake Game

A lightweight browser-based Snake game. Open the `index.html` file in any modern browser to start playing.

## Getting Started

1. Download or clone this repository.
2. Open the `index.html` file directly in your preferred web browser (Chrome, Firefox, Edge, Safari, etc.).

No build step or server is required—the game runs entirely in the browser.

## Controls

- **Move Up:** Arrow Up or `W`
- **Move Down:** Arrow Down or `S`
- **Move Left:** Arrow Left or `A`
- **Move Right:** Arrow Right or `D`
- **Restart:** Click the **Restart** button, press **Space**, or press **Enter** when the game is over.

## Features

- Smooth snake movement on a 20x20 grid.
- Randomly spawning food with increasing score (+10 per food).
- Collision detection for walls and self-hits resulting in game over.
- Responsive layout with a styled play area and score display.
- Accessible status updates and controls for restarting the game.
